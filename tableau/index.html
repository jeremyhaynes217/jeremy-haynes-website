Tableau

I have used Tableau extensively to develop dashboards and reporting solutions, including work in Tableau Server and Tableau Cloud environments. The work involves more than moving a workbook: data connections, refresh schedules, subscriptions, custom views, permissions and the behavior users expect all need attention during a transition.

Migration and operations

On enterprise migration engagements, I supported Server-to-Cloud moves and created Python tooling to handle repeatable migration tasks. I focus on a clear inventory, consistent execution and checks after migration so a workbook is usable in its new environment.

Analysis and communication

For dashboard work, I favor readable charts, meaningful filters and explanations that keep a metric in context. Tableau Public also gives me room to explore personal data projects, including a National Park Passport tracker.
