Power BI & Business Intelligence

Good BI development begins before the first visual. I work with stakeholders to define the question, identify a useful grain for the data and agree on the business rules behind the metrics. The model and measures should make those definitions reusable across pages and reports.

Power BI development

My Power BI work includes SQL-backed datasets, import and DirectQuery approaches, date logic, DAX measures, dimensional modeling, report interactions and documentation. I consider refresh cadence, query behavior and model size alongside the user experience. When a report feels slow or produces surprising numbers, I work from the source query through relationships, filters and measure context to find the cause.

Validation and delivery

I reconcile key figures against the source, test edge cases and document assumptions. User guides and technical notes help stakeholders use the report while giving future maintainers enough context to extend it.
